# Zavi TV Launcher

Android TV / Android box launcher: Zavi TV PIP (live channels + M3U playlist), weather (current location / any city),
analog + digital clock (seconds, multiple styles), 10 glass theme colours, PIP size (−/+), PIP hover controls
(prev/next, volume, mute), apni apps add karne wale tiles, WiFi shortcut.

## GitHub par APK
1. Files repo me upload karein (folder structure same).
2. Actions → Build APK → Run workflow.
3. Artifacts → AnalogTV-apk se `app-debug.apk` download karein.

## Use
* PIP par mouse le jayein: Prev / Vol- / Mute / Vol+ / Next. Click = fullscreen. Long-press (OK dabaye rakhein) = Channels menu.
* Channels: Playlist (M3U) link ya single stream link. PIP par LEFT/RIGHT ya CH+/CH-.
* Weather card: Current location, shehar ki list ya kisi bhi shehar ka naam.
* Clock card: analog/digital style. WiFi icon: WiFi settings. "Add App" tile: apni app home par. (Hatane ke liye tile par long-press.)
* IPTV tile: server + username + password (Xtream Codes) se Live TV / Movies / Series. Poora get.php link bhi paste kar sakte hain. Long-press = account badlein.
